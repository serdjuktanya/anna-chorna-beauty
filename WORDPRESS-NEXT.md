# Перенос Anna Chorna на WordPress

Сейчас Anna Chorna v2.7 — **статический HTML/CSS/JS прототип**. Он не является готовой темой WordPress, и данный ZIP нельзя загружать в раздел «Темы».

## Новости и блог
- Страница `journal.html` — внешний макет будущего архива записей WordPress (`home.php`/`archive.php`).
- Страницы `journal-hair.html`, `journal-makeup.html`, `journal-ritual.html` — макеты `single.php` для отдельных записей.
- Файл `wordpress-journal-drafts.xml` — 3 **черновика** для импорта через WordPress → Инструменты → Импорт → WordPress (может понадобиться WordPress Importer). Никаких вымышленных новостей или дат публикации.
- При переносе появятся редактируемые записи, категории, дата, excerpt, featured image, пагинация; ссылки меню заменяются `get_permalink()` / `get_post_type_archive_link()`; нужно настроить ЧПУ и breadcrumbs.
- Изображения карточек будущего блога сейчас абстрактные CSS-обложки (без сторонних фото и повторов). При желании в WP можно назначить каждому посту своё featured image.

## Сам сайт
Главная и услуги — `front-page.php`, `page-leistungen.php`; страницы Галерея, Об Анне, Контакт, юридические — отдельные page templates. Общие header/footer вынести в `header.php` и `footer.php`, ассеты ставить через `wp_enqueue_style/script`. Связать контактные данные и локации с настраиваемыми полями; реальные SEO meta и JSON-LD формировать уже по фактическому домену.
